## Featured Projects

### Medora
![Solo project](https://img.shields.io/badge/Solo-555555?style=flat-square) ![Live](https://img.shields.io/badge/Live-4A6FA5?style=flat-square)

Healthcare appointment scheduling for patients and doctors, replacing a manual booking workflow.

- 3-step digital booking flow in place of a manual scheduling process
- 12+ protected REST endpoints across two role-based dashboards, with JWT authorization enforced at route level
- Atomic transactions on slot rescheduling, so a slot is never left half-booked

**Stack:** React 19 · Node.js · Express 5 · PostgreSQL · Prisma · JWT · Docker
[Live demo](https://healthcare-medora.vercel.app/) · [Source](https://github.com/priyanshujha004/medora)

### SyncCare
![Team project](https://img.shields.io/badge/Team-555555?style=flat-square) ![My role: ML and backend](https://img.shields.io/badge/My_role-ML_%26_Backend-4A6FA5?style=flat-square) ![In development](https://img.shields.io/badge/Status-In_development-555555?style=flat-square)

- **In progress:** backend (Node.js, Express, PostgreSQL, Prisma)
- **Planned:** RAG-based health assistant, prescription OCR, patient and doctor management
