## 🚀 Featured Projects

- 🏥 **Medora** `Healthcare Appointment Scheduling` · **Live** · Solo project
  A scheduling platform for patients and doctors that replaces a manual booking workflow with a 3-step digital flow. It has 12+ protected REST endpoints across two role-based dashboards, with JWT authorization enforced at route level, and uses atomic transactions on slot rescheduling so a slot is never left half-booked.
  ![React](https://img.shields.io/badge/React_19-61DAFB?style=flat-square&logo=react&logoColor=black) ![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white) ![Express](https://img.shields.io/badge/Express_5-000000?style=flat-square&logo=express&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white) ![Prisma](https://img.shields.io/badge/Prisma-2D3748?style=flat-square&logo=prisma&logoColor=white) ![JWT](https://img.shields.io/badge/JWT_Auth-FF007F?style=flat-square) ![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)
  [GitHub Repo](https://github.com/priyanshujha004/medora) · [Live Demo](https://healthcare-medora.vercel.app/)

- 💰 **UPIQ** `Personal Finance Tracker` · **Live** · Team project (my role: frontend)
  A finance tracker that parses bank PDF statements into categorized transactions, secured with JWT. I built the React frontend: reusable components for transaction dashboards, authentication flows and expense tracking, integrated with the Spring Boot REST APIs, with state management, client-side routing and form validation.
  ![React](https://img.shields.io/badge/React-61DAFB?style=flat-square&logo=react&logoColor=black) ![Spring Boot](https://img.shields.io/badge/Spring_Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white) ![JWT](https://img.shields.io/badge/JWT_Auth-FF007F?style=flat-square) ![Docker](https://img.shields.io/badge/Docker-2496ED?style=flat-square&logo=docker&logoColor=white)
  [GitHub Repo](https://github.com/yourxharsh19/UPIQ-PROD) · [Live Demo](https://upiq.vercel.app)

- 🧬 **SyncCare** `AI-Assisted Healthcare Platform` · **In Progress** · Team project (my role: ML & backend)
  A healthcare platform for patients and doctors with disease prediction, a RAG-based health assistant, prescription OCR and appointment management. The first ML version is done: after comparing existing models I chose Random Forest, trained on 3.6M records with an 80/20 train-test split, reaching 95.32% accuracy. The backend is under development.
  ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Random Forest](https://img.shields.io/badge/Random_Forest-FF9900?style=flat-square) ![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=nodedotjs&logoColor=white) ![Express](https://img.shields.io/badge/Express-000000?style=flat-square&logo=express&logoColor=white) ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white) ![Prisma](https://img.shields.io/badge/Prisma-2D3748?style=flat-square&logo=prisma&logoColor=white)
